# Locally packaged Google Fonts

Downloaded from the same Google Fonts CSS URLs already used by the website. WOFF2 filenames use a hash of their original fonts.gstatic.com URL. Font licenses are included alongside the files.

- https://fonts.googleapis.com/css2?family=Inter:wght@500;600&family=Manrope:wght@500;600;700&family=Playfair+Display:wght@600;700&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap
- https://fonts.googleapis.com/css2?family=Roboto:wght@400;500&family=Roboto+Condensed:wght@400;700&display=swap
- https://fonts.googleapis.com/css2?family=Satisfy&display=swap
