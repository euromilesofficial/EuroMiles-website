# EuroMiles subject icons

Original flat SVG line artwork created for EuroMiles using the user’s approved
mockup as visual direction. Consistent 32-unit viewBox, navy (#0b2046),
rounded linework, and no external fonts, scripts or image dependencies.

Engineering uses Lucide's `cog` geometry, downloaded 18 October 2026:
https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/cog.svg
Stroke colour and weight adapted to match EuroMiles. ISC license included
as `LICENSE-lucide.txt`. The other seven icons are unchanged original artwork.
